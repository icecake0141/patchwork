# Patchwork

Patchwork is a Flask-based assistant for deterministic rack-to-rack patch cabling design.

## Installation

```bash
git clone https://github.com/icecake0141/patchwork.git
cd patchwork
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Start the app:

```bash
python app.py
```

Open `http://localhost:5000/upload`.
